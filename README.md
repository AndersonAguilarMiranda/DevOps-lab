# DevOps Home Lab

## Objetivo

Laboratorio personal para aprender DevOps mediante la documentación, automatización y monitorización de servicios locales.

## Entorno actual

- **Sistema operativo:** CachyOS Linux
- **Entorno de escritorio:** Hyprland
- **Contenedores:** Podman
- **IA local:** llama.cpp y OpenCode
- **Virtualización:** KVM/libvirt y virt-manager
- **Seguridad y monitorización:** Wazuh

## Objetivos de aprendizaje

- [ ] Documentar la infraestructura actual.
- [ ] Crear scripts de automatización con Bash.
- [ ] Documentar y gestionar contenedores.
- [ ] Añadir validaciones con GitHub Actions.
- [ ] Aprender Ansible para configurar sistemas.
- [ ] Explorar Terraform e infraestructura como código.
- [ ] Mejorar la monitorización y la seguridad.

## Seguridad

No almacenar credenciales, tokens, claves privadas ni secretos en el repositorio.
